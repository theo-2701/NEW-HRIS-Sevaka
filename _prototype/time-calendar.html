Calendar

Two resources answer one question — is this date a working day? Holidays carry two layers: a national layer seeded automatically from government decrees, and a regional/company layer entered by HR that only takes effect after maker–checker approval. Work calendars set the weekly working pattern and always apply forward.

National rows are seeded by the system — locked, always approved on arrival, and never editable from this screen. A row entered here is born Draft and affects nothing; there is no separate submit endpoint — saving the edit form on a Draft row is the submission, and the date only becomes a real holiday once a different HR admin approves it. A live row already holds its date × type × scope slot — including a rejected one, which must be deleted before the slot is free again (409).
Patterns are prospective — a running pattern is never edited, it is ended and replaced.
