Other Files

Documents attached to an object — asset, vendor or branch — never to a person or to the company itself. owner_type=OBJEK_LAIN. Fully read-only, and zero calls to employee-service, so there is no two-long fail-closed chain here.

OF-2 · owner_object_kind classification

ASET → company.mst_asset · VENDOR → company.mst_vendor · CABANG → company.mst_branch — each one a PICKER → company-service. Pure classification; this screen has no concept of a “document owner”, so the owner-opens-own-file path (DOC-30) does not apply.

The letter block is always null here

Letters are always owned by an employee or by the company, never by an object. A2/A4 are identical across all four file screens — drawing a second variant is forbidden.

Stated difference against the Figma frame

Frame S1 in Main-Frame draws only two filters (object kind, object). The Category control has been in the A3 contract since TSD 0.1 and its source address (A16) landed in TSD 0.3 — visual debt, not contract debt (PROB-SERVICE-406 category side is CLOSE).
