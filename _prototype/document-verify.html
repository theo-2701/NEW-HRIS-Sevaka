Confirm that a letter issued by PTDIKA is genuine. This page answers match or no match — nothing else. No sign-in, no token, no account.

Carried from the QR link. The form itself is the visual shape of one GET /verify/{verification-code} reply — which looks identical whether the code exists or never existed.

One button, two outcomes — decided by the server

Five different causes land on the exact same “no match” answer: the code never existed · it belongs to another company · the letter is not issued yet · the number belongs to an EDARAN letter · the name does not match. Colouring them differently is forbidden. There is also no 404 here — answering “not found” would confirm that a code exists.
