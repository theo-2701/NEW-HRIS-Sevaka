Integration Contact

The external person the system writes to for this company — used by notification service for integration alerts. One contact per company; both fields are optional.

Singleton record — there is no list, no create and no delete. Saving overwrites the single row; clearing both fields empties it. When empty, integration alerts for this company are skipped. Read and write are both limited to Super Admin and System Admin.
Where integration and payroll alarm notices are sent.
