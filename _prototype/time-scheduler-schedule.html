Scheduler Schedule

The three write surfaces behind the roster: the shift pattern catalogue, the roster rows themselves (one at a time or in bulk), and shift swaps. Bulk assignment deliberately skips rows already locked by an individual adjustment or a swap — it never overwrites them.

The shift type is locked once the pattern exists — a pattern created with the wrong type is retired and replaced, never re-typed. Crossing midnight is derived from the end time being earlier than the start time; it is not a separate input. A cycle pattern never appears in the roster picker because it has no hours of its own until it is materialised.
