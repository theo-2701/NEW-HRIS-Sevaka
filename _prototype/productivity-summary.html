Deliberate boundary. This screen never queries attendance in the time service, and carries no difference-against-attendance column. Payroll integration fields (unpaid minutes, per-paid-group breakdown) are server-to-server and intentionally not rendered.

No client-facing endpoint moves this forward. MENUNGGU_PENGESAHAN → DISAHKAN / DIKEMBALIKAN happens only when the workflow service publishes its completed or cancelled event — so this screen never carries an Approve or Reject button, for any role. The owner's only action is Submit, gated on no system-stopped row being left unsettled.

DIKEMBALIKAN is reachable from two directions — a cancelled workflow decision, or a reopen from DISAHKAN by the direct manager or HR while payroll has not confirmed. Both land in the same state, and re-submission uses the very same endpoint with a fresh workflow instance.
