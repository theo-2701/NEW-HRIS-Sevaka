No upload button, no delete button

Uploading is Regime B (server-to-server, on behalf of the owning service). There is no Delete anywhere in Document Service (DOC-37) — files only disappear through the scheduled sweep.

“Withheld from owner” has no human lever

A withheld row is simply absent from this list. What you see is the consequence, not a toggle or a marker (DOC-30.4/5).

shown_in_self_service ≠ authorization

It governs what this screen lists, not what the door permits. A file hidden from this list is still reachable through the employee-service screen that owns its disclosure timing.
