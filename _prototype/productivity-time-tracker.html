Time Tracker

Two equally contracted ways to record hours for yourself: a running counter (DIUKUR_MESIN, always carries clock times) and a typed entry (DIKETIK_MANUSIA, never carries them). Both land in the same table and are corrected on Activities.

The previous counter was stopped automatically. Only one counter may run at a time, so starting a new one closes the old one — announced here, never silently.
