Salary Processing

Run and recalculate a payroll period, review the numbers, close the 13 kinds of non-blocking findings, and import the running-year payroll history of migrated employees. Locking, reopening and handover authorisation belong to the checker in Authorization & Handover.

Acting as Rudi Hartono — ROLE_PAYROLL_OFFICER. One form, two server branches: Run period inserts a new period (201) or recalculates an existing CALCULATED one (200) from the same endpoint. Gates 1 (time reconciliation) and 2 (finance deduction pull) are read-only here — they are only evaluated when the checker locks the period; gate 3 (param snapshot complete) is derived, and the ten parameters freeze in the same transaction as the run.
