Time Off Request

Leave is always requested for oneself. Ordinary leave waits for a decision and touches nothing until it lands; sick leave takes effect immediately and instead opens a bounded window in which a manager may still reject it. A request is checked against four submit gates before a row is ever created.

Reject sick leave

Only available inside the frozen reject window. Rejecting reverses what already took effect — the balance is returned and the day falls back to absent.

Withdraw this request?

Allowed while pending or auto-approved, and — once approved — only before the start date arrives.

If the balance was already deducted it is written back as a reversing ledger entry, the dates are released, and any delegation attached to this request is cancelled with it.
