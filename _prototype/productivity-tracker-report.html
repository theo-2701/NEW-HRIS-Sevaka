Read-only by contract. There is no create, edit or delete on this surface — corrections belong to the owner on Activities. Each row read here writes exactly one access-trail entry; a refused read writes none, which is what makes the trail usable as evidence in an IDOR/BOLA test. Columns follow the contract grid — code, employee, work date, task, duration, origin — plus activity type, which the search shape adds on this surface. Clock times stay on Activities, where the owner can act on them.
The export format (CSV / XLSX) is a presentation-layer concern outside the data contract — the export icon above the grid is a real placeholder for it, not an invented feature.
