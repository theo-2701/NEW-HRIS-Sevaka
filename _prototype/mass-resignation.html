Review batch

Checker must outrank the maker and differ from them. Approval freezes the selection hash.

Rank-guard: checker must be HR Manager or above and differ from the maker (SoD). The frozen hash prevents the selection changing between approval and processing (anti-TOCTOU).

Process batch

Send the frozen selection hash to start throttled offboarding. A mismatch is rejected.

The hash must match the selection frozen at approval. A mismatch is rejected with 409 Conflict — the batch stays APPROVED and nothing is spawned (anti-TOCTOU).
A batch correlation id is attached to every spawned offboarding so the run can be halted or bulk-suspended as one.

Halt processing

The circuit-breaker suspends running offboarding instances by correlation id.

Halting freezes the remaining employees in this batch. Already-processed employees are not reverted.

Resume or cancel

Continue the remaining employees, or cancel them and finish as partial.
